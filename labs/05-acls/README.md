# Lab 5 — Access Control Lists

## Objective
Control which departments can communicate with each other using Cisco ACLs.

## Security Policy
- IT may reach all internal networks
- Sales must not access HR
- HR may access approved shared services
- Required business traffic should continue to work

## Tasks
- [ ] Build the policy before writing commands
- [ ] Configure a standard or extended ACL as appropriate
- [ ] Apply the ACL in the correct direction/interface
- [ ] Verify allowed traffic
- [ ] Verify blocked traffic
- [ ] Inspect ACL counters
- [ ] Break one rule intentionally and troubleshoot it

## Skills
- Permit vs deny
- Source and destination matching
- ACL order
- Implicit deny
- Placement and direction
