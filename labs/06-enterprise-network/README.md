# Lab 6 — Mini Enterprise Network

## Objective
Combine the earlier networking skills into one realistic small-enterprise design.

## Planned Components
- Internet edge router
- Core/distribution switch
- HR VLAN
- Sales VLAN
- IT VLAN
- Server VLAN
- DHCP
- DNS
- Inter-VLAN routing
- ACL-based segmentation
- Monitoring/troubleshooting documentation

## Tasks
- [ ] Draw the logical topology
- [ ] Create an IP addressing plan
- [ ] Configure switching and VLANs
- [ ] Configure routing
- [ ] Configure DHCP and DNS
- [ ] Apply access-control policies
- [ ] Validate end-to-end connectivity
- [ ] Create at least 5 fault scenarios
- [ ] Diagnose and document each fault

## Fault Scenarios
Examples:
- Wrong subnet mask
- Wrong default gateway
- Incorrect VLAN assignment
- Shutdown switch port
- Bad ACL rule
- DHCP failure
- DNS failure

## Final Deliverables
- [ ] Packet Tracer file
- [ ] Network diagram
- [ ] Device configuration files
- [ ] Addressing table
- [ ] Security policy
- [ ] Verification screenshots
- [ ] Troubleshooting report
