# Lab 1 Evidence

This folder is reserved for **real Packet Tracer evidence** from the completed lab.

Add the following files after performing the lab:

1. `01-working-topology.png`
2. `02-successful-ping.png`
3. `03-failed-ping-subnet-mismatch.png`
4. `04-successful-ping-after-fix.png`
5. `lab01-basic-lan.pkt`

## Evidence Rules

- Screenshots must come from the actual Packet Tracer lab.
- Do not use generated illustrations as completion evidence.
- The topology should show PC0, Switch0 and PC1 with working links.
- The successful ping should show communication from PC0 to `192.168.10.20`.
- The failed ping should be captured after changing PC1 to `192.168.20.20/24`.
- The final screenshot should show connectivity restored after returning PC1 to `192.168.10.20/24`.

Once these files are present, Lab 1 can be marked complete.
